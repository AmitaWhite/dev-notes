# 테이블·컬럼 용어 사전

이 파일은 하나만 두고 계속 추가한다.

낯선 이름은 보통 **약어 조합**이다. 끝부분(접미사)이 데이터 종류를, 앞부분이 업무 대상을 나타내는 경우가 많다.
예: `CUST_STAT_CD` = 고객(CUST) + 상태(STAT) + 코드(CD)

아래 참고표는 흔한 관례이고, 현장 규칙은 테이블 정의서와 개발 표준으로 확인한다.

## 참고: 흔한 접미사

| 접미사 | 뜻 | 예 |
| --- | --- | --- |
| `_CD` | 코드값 (공통코드와 JOIN해 이름을 붙임) | `STAT_CD = '02'` |
| `_NM` | 이름 | `CUST_NM` |
| `_YN` | 여부 (Y / N) | `USE_YN`, `DEL_YN` |
| `_DT` / `_DTM` | 일자 / 일시 | `REG_DT` |
| `_SEQ` / `_NO` / `_ID` | 순번 / 번호 / 식별자 | `BOARD_SEQ` |
| `_AMT` | 금액 | `PAY_AMT` |
| `_CNT` / `_QTY` | 건수 / 수량 | `VIEW_CNT` |
| `_STAT` / `_STS` | 상태 | `APRV_STAT` |
| `_TP` / `_TYPE` / `_DIV` | 유형 / 구분 | `USER_TP` |
| `_DESC` / `_CN` / `_CONT` | 설명 / 내용 | `BOARD_CONT` |

## 참고: 거의 모든 테이블에 있는 컬럼

| 컬럼 | 뜻 |
| --- | --- |
| `REG_ID`, `REG_DT` (또는 `CRT_`, `INS_`) | 등록자, 등록일시 |
| `MOD_ID`, `MOD_DT` (또는 `UPD_`, `CHG_`) | 수정자, 수정일시 |
| `USE_YN` | 사용 여부 |
| `DEL_YN` | 삭제 여부 (실제로 지우지 않고 표시만 하는 논리 삭제) |
